1.Factorial with Tail Recursion and Accumulators:
	Accumulator: The accumulator is used to store the output at each step (from largest to smallest), and this value is then passed to the next call. The call being the last procedure makes it tail recursive.
	Input validation: The first definition of factorial (which means it gets checked before other predicates) compares the type of the 1st input and whether it's smaller than 0, in that order, setting the result to the error message if either condition is true. This ensures no negative or non-integers get through, and that the conditions are applied correctly.

	Recursive Logic: For each item in the list, it passes it to a works predicate. This works predicate iterates through each condition (used with the call predicat), and ultimately returns true if all conditions have been met. If this is successful, it calls filter_list with the tail to try with the remaining items, and adds the head to the output list. Once there are no more items, it sets the output list as an empty for all the other items to add to, and cuts so that the first solution is the only one kept.
